    How it works

    1. Upload a Nepali audio clip (interview, speech, song, voice note).
    2. Transcribe with OpenAI's Whisper running locally in your browser via WebGPU.
    3. Review time-coded segments, click any time code to jump, edit text inline.
    4. Export as SRT/VTT subtitles, timestamped TXT, or JSON.

    Long recordings are processed in 30-second windows. Very long files (1 hr+) are best on a desktop with WebGPU; the smaller model is faster on modest devices. Nothing is uploaded anywhere.
